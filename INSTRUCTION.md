# MarketPay USSD — User Guide

## Dialling the Service

Dial the USSD code provided by Monime on your phone. If you're allowed, you'll see the MarketPay menu.

## Menu Options

After passing the access check, you'll see:

### 1. Register vendor
Use this if you are **not** already registered. Enter your name and market. You only need to do this once.

### 2. Pay vendor
1. Enter the vendor code (e.g. MP12345)
2. Enter the amount in SLE
3. Confirm the payment
4. Enter your PIN to complete

### 3. Transaction history
View your recent transactions.

### 4. Check balance
See your outstanding loan balance.

### 5. Loan eligibility
Check if you qualify for a loan.

### 6. Loan application
1. Enter the loan amount
2. Confirm to submit
3. You'll receive a tracking number

### 7. Exit
End the session.
